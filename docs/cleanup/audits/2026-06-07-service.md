# Service Vocabulary Audit

## Scope

Audit command:

```powershell
rg -n "\bservices?\b|Service|Services|\.service\b|service =|local service\b|storageService|planService|definitionService" src tests docs API.md
```

## Result

`service` remains intentional internal vocabulary for subsystem bundle surfaces.
Renaming those bundle fields to `runtime` was rejected because `runtime` already
means callback runtime context, framework runtime, and hot-reload runtime state.

The cleanup kept only local helper names where `service` was vague:

- `storageService` -> `storageApi`
- `definitionService` -> `definitionApi`
- `planService` -> `planApi`

Historical audit files still contain old matches by design.
